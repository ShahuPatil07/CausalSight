# EXP-005: object-color binding under controlled interventions

Status on 2026-10-11: Colab development and evaluation complete. Imported run EXP-005-colab-d4f38207 passed provenance validation and local metric recomputation. The visual model reaches the ceiling on this task.

## Question and hypothesis

Does Qwen3-VL-2B-Instruct answer about the named object, correctly update when that object's color changes, and preserve its answer when only the other object changes? The exploratory hypothesis is that some failures may reflect target/distractor confusion despite ordinary original accuracy. A ceiling result is also informative: this task may be too easy to expose useful weaknesses.

This design follows controlled synthetic diagnostics and answer-changing/answer-preserving edits, rather than claiming a new intervention concept. Related work: [CLEVR](https://arxiv.org/abs/1612.06890), [Towards Causal VQA](https://arxiv.org/abs/1912.07538).

## Dataset and controls

Immutable `data/binding-v1`, seed 11017. Evaluation has 128 independently seeded scene families: two renderings of every combination of target shape (2), target side (2), target color (4), and distractor color (4). Development has 16 separate families covering target shape, side and target color. Development is not a balanced copy of evaluation and does not claim coverage of every color transition.

Each family has four inputs: original, target-color edit, distractor-color edit, and original image with the question switched to the other shape. Geometry and wording stay fixed for visual edits; question switching preserves the exact original PNG. Color replacements always differ from the previous color. Evaluation includes every directed color transition 10 or 11 times, rather than claiming exact transition balance. Original labels and the two edited-color marginals are balanced across four colors. There are 32 same-color and 96 different-color evaluation originals; report these separately.

There are 576 manifest rows and 432 PNGs: 64 development requests plus 512 evaluation requests; question-switch rows reuse original PNGs. Geometry jitter changes sizes and centers between families. These are variations of one rendering/question template, not held-out templates or natural-image generalization. The audit checks exact rendered pixels, intended field changes, labels, question switches, duplicate original inputs, split image separation and the factorial balance.

## Baselines and measurements

Metadata baselines: constant red, leftmost-object color, other-than-queried-object color. Run them through the same manifest-backed evaluator. They are explicit shortcuts, not VLM inference.

Text-only baseline: one actual request per unique question (two per split). Project responses onto corresponding scene labels and link every projected row to its source request ID. Do not present the projection as hundreds of independent requests. Refusals are retained and scored separately as unparsed responses; lack of an image makes refusal reasonable.

Measurements: original accuracy; causal edited-target accuracy; correct causal update (both original and causal correct, with different predictions); nuisance invariance; correct nuisance preservation; consistently wrong invariance; all-three-correct triplets; both-correct question switches for different-color originals and a separate same-color stratum. Save numerators and denominators, paired predictions, status/parse/truncation diagnostics, and shape/position/color strata. Only final answer content is scored. The strict parser accepts a single color word with optional final period/exclamation mark; it does not extract colors from prose, refusals, negations or thinking traces.

Missing rows and request/parse failures remain in the full manifest denominators. Reject duplicate, unknown, mismatched-label and mixed-run predictions. Preserve aborted rows and partial reports. Resume skips all saved rows, including errors, and generates a new analysis directory; it never selectively retries failures.

Report finite-grid descriptive rates. Do not attach independent-image confidence intervals to paired families or claim population generalization. A later confirmatory design must address more templates, repeats, sampling and uncertainty.

Interpretation: the model succeeds on the tested simple synthetic controls and exceeds the shortcut baselines. This is a ceiling result, not evidence of broad grounding or an internal causal mechanism. Next scientific work should increase task difficulty (for example counting or relational/spatial evidence) and design new controls/templates before inference. Do not tune or reuse these evaluation outcomes as an unseen test set.
